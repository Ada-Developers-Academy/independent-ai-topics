# Setting up Our Workspace

We'll be using two tools to provide free access to large language models for coding agents.
- Github Copilot, through the GitHub Student Develoepr Pack
- OpenRouter

Both of these will be used from inside VS Code, keeping our tools in one location so we don't need to leave our IDE to add agents to our workflow.

Note: students that already have or choose to later procure their own subscriptions to other LLM providers are welcome to use those, but instructor support for how to integrate those into the Ada toolset may be limited.
